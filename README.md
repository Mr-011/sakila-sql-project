
# Sakila SQL Project 

This project contains SQL queries analyzing the Sakila movie rental database using MySQL Workbench.

## Queries included
- Top rented films  
- Revenue per film  
- Top customers  
- Films per category  
- Sales by country

## Tools
- MySQL Workbench  
- SQL

  
You can find all SQL queries in the file [sakila_project.sql](sakila_project.sql).
